## Problem No. 3 - Last Digit

**Input file**: last.in **Output file**: Standard Output

The number of permutation without repetition that has a string $S$ is so big, but in the problem you just need to print the last nonzero digit of it.

### Input
In each test case you have a string $S ( 1 <= |S| <= 1000000)$, all characters in the string are lowercase.

### Output
For each test case print the last nonzero digit.

| Sample Input | Sample Output |
| - | - |
| aaba | 4 |
| aaabababababa | 7 |
| abbzazaazzalzalzzaaaaazlalzaazlalzla | 8 |
| w | 1 |

For example for the first test case the permutation are:<br/>
aaab<br>
aaba<br>
abaa<br>
baaa
